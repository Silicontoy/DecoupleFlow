# Pick a notes tool

Choose one option for a **single user** who requires **offline access** and **Markdown export**. Compare Local Notes, Team Notes, and Cloud Notes using only the three supplied files.

Deliver a comparison table, a recommendation, citations to the supplied files, and unresolved questions. If a capability is missing from a source, write **unknown**.

All products and specifications in this demo are fictional. This is a source-checking exercise, not purchasing advice.
