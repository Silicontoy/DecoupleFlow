The screenshots and GIF show DecoupleFlow **0.5.0**, with Mermaid **11.17.2**. The exact capture date, resolution, filenames, and demo chapter times are in [media-manifest.json](media-manifest.json).

![Core demo](demo.gif)

The recording walks through a state machine, an ordered list and shared condition, the Markdown/Mermaid description, export routes, and a real exported Skill's execution window through completion and automatic archiving. A small deterministic demo harness supplies fixture evidence; the recording does not depict an actual Codex or Jev model call. The separate [Codex harness](../examples/codex-resume/) demonstrates a real model session.

Public captures use English example definitions and sample directory-discovery data to avoid including the operator's personal home or project history. The interface, downloaded ZIP, standalone viewer, persisted records, and transitions run normally.

## Regenerate

The READMEs also include three **illustrations** in English and Chinese: [use cases](diagrams/use-cases.en.svg), [workflow](diagrams/workflow.en.svg), and [install and use](diagrams/install.en.svg). They explain the interaction rather than reproduce a screenshot. Their self-contained SVG source is generated by [draw-readme-diagrams.mjs](../scripts/draw-readme-diagrams.mjs). Regenerate all six SVGs with `npm run docs:diagrams`; no browser, external fonts, or image service is needed.

Start the production build in one terminal:

```bash
npm ci
npm run build
npm start
```

In a second terminal, with Chromium and FFmpeg installed:

```bash
npx playwright install chromium
npm run docs:media
```

Optional variables: `MEDIA_BASE_URL` selects the local running editor; `PLAYWRIGHT_CHROMIUM_EXECUTABLE` selects an existing Chromium executable; `FFMPEG_PATH` selects FFmpeg. The script uses an isolated browser context, does not change your browser workspace, downloads its own Skill, and writes temporary recordings/instances to the ignored `.media-work/` directory. It refreshes every image in the table and creates an 8 fps, 1152-pixel-wide GIF between 45 and 55 seconds long.
